The project is essentially a Notion for movie enthusiasts. Here, users can create their own collections, share them with friends, attach flags to movies, leave comments under other users’ collections, compare tastes, and view statistics.

Below is a more detailed explanation of each feature.

1. Flags

Flags are a unique attribute assigned to movies. They allow a user to express their taste and attitude toward a film with a single word.

In addition, every flag must belong to a specific category. For example:

Blood Level:

Low — light background presence, not disturbing

Medium — a more noticeable background level

High — heavy presence

Gorefest

Naturally, the project will include a dedicated page for creating and managing these flags. Users will be able to choose a background, an SVG icon, and a font, and assign the flag to a category. A real-time preview will be available. Users will also be able to see how the flags will appear on a movie card and how they will look visually.

2. Creating Collections

Nothing extraordinary here. It’s a standard system for creating folders where movies can be stored. There will also be a dedicated page for creating and managing collections.

3. Main Page (Home)

This is the landing page that welcomes users.

Instead of simple cards, the page will display decks, since the focus is on collections rather than individual movies. Clicking on a deck will open the page of that collection. On that page, users will be able to see the author, leave a comment, rate the collection, or share it. They will also be able to compare their tastes with the author and view all of the author’s other collections.

4. Adding Movies Manually

Sometimes a movie may not exist in the database. These might be rare films or very niche ones.

This feature will allow users to add a movie manually by filling in all the necessary fields for a film, TV series, or animated work. This will be a Premium feature, unavailable to regular users.

5. Statistics

In both their own profile and another user’s profile, users will be able to view four available statistics blocks.

World Map — a map displaying circles over countries that represent the number of films added from each country.

(Other statistics blocks to be defined.)

6. Settings

The settings will allow users to customize the website interface, especially the movie card, with a very high level of flexibility. Users will be able to configure highly complex layouts for how content is displayed on the cards.
